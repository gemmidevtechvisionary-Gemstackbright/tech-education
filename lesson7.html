មេរៀនទី ៧៖ ការប្រើប្រាស់ Lists (បញ្ជីរាយនាម)

Lists ត្រូវបានប្រើប្រាស់សម្រាប់ដាក់រាយបញ្ជីព័ត៌មានផ្សេងៗក្នុង HTML ដែលមានពីរប្រភេទសំខាន់គឺ Ordered List (រៀងលេខ) និង Unordered List (រៀងសញ្ញាសម្គាល់)។

លទ្ធផលបង្ហាញជាក់ស្តែង៖

  • HTML (HyperText Markup Language)
  • CSS (Cascading Style Sheets)
  • JavaScript (Programming Language)

កូដ HTML ដែលត្រូវសរសេរ៖

<ul>
    <li>HTML (HyperText Markup Language)</li>
    <li>CSS (Cascading Style Sheets)</li>
    <li>JavaScript (Programming Language)</li>
</ul>

ការពន្យល់កូដ៖

  • <ul>៖ បង្កើតបញ្ជីរាយគ្មានលេខរៀង (Unordered List)។
  • <ol>៖ បង្កើតបញ្ជីរាយមានលេខរៀង (Ordered List)។
  • <li>៖ បង្កើតជម្រើស ឬធាតុនីមួយៗក្នុងបញ្ជី (List Item)។
មេរៀនមុន ទំព័រដើម មេរៀនបន្ទាប់
