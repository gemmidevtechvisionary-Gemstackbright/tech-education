មេរៀនទី១៖ HTML & CSS Basics

មូលដ្ឋានគ្រឹះនៃការសាងសង់ទំព័រវេបសាយ

១. តើអ្វីជា HTML?

HTML (HyperText Markup Language) គឺជាភាសាគ្រោងឆ្អឹងសម្រាប់បង្កើតទំព័រវេបសាយ។ វាប្រើប្រាស់ Tags ដូចជា <h1> សម្រាប់ចំណងជើង និង <p> សម្រាប់អត្ថបទ។

២. តើអ្វីជា CSS?

CSS (Cascading Style Sheets) គឺជាភាសាសម្រាប់តុបតែងរចនាសម្ព័ន្ធ HTML ឱ្យមានពណ៌ផ្ទៃ ពណ៌អក្សរ ទំហំ និងប្លង់រៀបចំយ៉ាងស្រស់ស្អាត។

៣. ឧទាហរណ៍កូដ HTML ខ្លីៗ៖

<h1>សួស្តីពិភពលោក</h1>
<p>នេះគឺជាវេបសាយដំបូងរបស់ខ្ញុំ។</p>
