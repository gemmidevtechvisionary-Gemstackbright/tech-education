⬅️ ត្រឡប់

តើ Git និង GitHub គឺអ្វី?

Git គឺជាប្រព័ន្ធគ្រប់គ្រងកំណែទម្រង់កូដ (Version Control) ដែលរត់ក្នុងម៉ាស៊ីនយើងផ្ទាល់ (Termux) រីឯ GitHub គឺជាកន្លែងផ្ទុកកូដនៅលើអនឡាញដើម្បីឱ្យអ្នកដទៃអាចមើលឃើញ។

ពាក្យបញ្ជា Git សំខាន់ៗ៖

  • git add . : រៀបចំឯកសារទាំងអស់ត្រៀមបញ្ជូន
  • git commit -m "សាររៀបរាប់" : រក្សាទុកដំណាក់កាលកូដ
  • git push : បញ្ជូនកូដឡើងទៅកាន់ GitHub
