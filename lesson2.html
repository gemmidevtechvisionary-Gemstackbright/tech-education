មេរៀនទី២៖ ការលម្អរចនាដោយ CSS3

CSS (Cascading Style Sheets) គឺជាភាសាដែលប្រើសម្រាប់តុបតែង និងកំណត់ប្លង់ (Layout) របស់វេែបសាយ HTML របស់អ្នកឱ្យមានភាពទាក់ទាញ និងស្រស់ស្អាត។

១. អ្វីទៅជា CSS?

ប្រសិនបើ HTML ប្រៀបដូចជាគ្រោងឆ្អឹង ឬផ្ទះអត់ទាន់បូកបាយអ នោះ CSS ប្រៀបដូចជាការលាបពណ៌ ការតុបតែងគ្រឿងសង្ហារឹម និងរៀបចំសោភ័ណភាពនៃផ្ទះនោះឱ្យគួរឱ្យចង់រស់នៅ។

២. វិធីសាស្ត្រដាក់កូដ CSS

យើងអាចសរសេរ CSS បាន ៣ របៀប៖

  • Inline CSS: សរសេរផ្ទាល់ក្នុង Tag តាមរយៈ attribute style។
  • Internal CSS: សរសេរក្នុង Tag <style> នៅផ្នែក <head> នៃទំព័រ HTML។
  • External CSS: សរសេរក្នុងហ្វាលដាច់ដោយឡែក (ដូចជាហ្វាល style.css របស់អ្នក) ហើយភ្ជាប់វាចូលមក។

៣. ឧទាហរណ៍កូដ CSS មូលដ្ឋាន

កូដខាងក្រោមនេះប្រើសម្រាប់កំណត់ពណ៌ផ្ទៃខាងក្រោយ និងពណ៌អក្សរ៖


body {
    background-color: #f4f4f4;
    color: #333333;
    font-family: 'Khmer OS Siemreap', sans-serif;
}
